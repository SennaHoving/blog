Projecten

CSS

Een Rubik’s kubus die volledig in de browser leeft — gebouwd om te onderzoeken hoe mensen 3D-ruimte begrijpen met alleen muis en toets.

Vak

CSS

Tools

HTML, CSS

Het project

Bij dit project was het de opdracht om een volledig werkende rubiks kubus na te maken op het web. En dit exclusief in html en css. Tijdens dit project kwam de 3d aspecten van het web / css veel naar voren.

Proces

Kubus begon als een simpele vraag: kun je een fysiek, tactiel object zoals een Rubik’s kubus net zo intuïtief laten aanvoelen op een plat scherm? De meeste online varianten dwingen je in knoppen en menu’s; ik wilde dat draaien aan een zijde net zo vanzelfsprekend zou zijn als in je handen. Het resultaat is een kubus die je vrij kunt roteren en oplossen, met drie modi — classic, hyper en spin — die elk een ander gevoel van controle geven. Vervang deze alinea’s door je eigen tekst; de opmaak schaalt mee.
