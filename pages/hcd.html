Human Centered Design

Een groepschat die intonatie hoorbaar maakt voor een blinde gebruiker

Live demo Github repo

Vak

Human Centered Design

Tools

HTML, CSS, JavaScript

Het project

Bij HCD was de opdracht om een inclusieve applicatie te maken die volledig is afgestemd op één persoon: Berend, die slechtziend is en daardoor veel nuance en intonatie in tekst mist. Mijn eindproduct is een nagebouwde groepschat waarin elke deelnemer met een eigen stem wordt voorgelezen. Daardoor is in een gesprek met meerdere mensen veel sneller te volgen wie wat zegt. Daarbovenop kan de gebruiker bij het versturen van een bericht een emotie of toon meegeven.

Proces

Ik ben begonnen met SSML (Speech Synthesis Markup Language). De diensten van Microsoft en Google vroegen een abonnement, dus in eerste instantie heb ik het nagebootst met de text-to-speech uit de browser. Vanuit daar heb ik veel getest met Berend zelf. Die testmomenten waren cruciaal: ik merkte pas echt hoe Berend het web gebruikt toen ik zag dat hij maar met één element tegelijk bezig kan zijn, dat alles buiten zijn focus wegvalt, en hoe belangrijk duidelijke focus-states en contrast zijn. Het concept is meerdere keren verschoven — van een weersite, naar een webshop met verschillende tonen per element, tot uiteindelijk de groepschat. Die richting kwam voort uit Berends eigen opmerking dat hij intonatie vooral mist in blogs en in WhatsApp. Aan het eind kreeg ik de Google Cloud Text-to-Speech API werkend en heb ik het prototype zo aangepast dat berichten automatisch worden voorgelezen bij focus, zoals een echte applicatie zou werken.

Reflectie

Ik heb dit project gestructureerd rond vier design principles. Bij study situation heb ik bewust voor één context gekozen — die van Berend — en juist daardoor dingen ontdekt die ik anders had gemist. Bij ignore conventions leerde ik dat conventies prima zijn, maar vaak afgestemd op een kleinere doelgroep; de skip-knop naar het invoerveld voelde eerst overbodig, maar bleek voor Berend juist beter te werken dan de conventionele aanpak. Bij prioritise identity heb ik focus, contrast en het vergroten van berichten op zijn restzicht afgestemd. En add nonsense leverde het idee op om emotie aan berichten mee te geven — een idee dat eerst onnodig voelde, maar uiteindelijk goed bij het project paste. Vooral dat laatste principe maakt het voor mij makkelijker om te durven experimenteren met ideeën die in eerste instantie raar lijken.
